# 프렙 카페 단일 매장 MVP

기본 자료, 판매 입력·수정·삭제, 판매 엑셀 양식·가져오기, 메뉴 수익성, 비용 입력·수정·삭제, 기간 손익, 입고·폐기·실제 재고, 월말 예상, 부족·발주 참고와 전체 JSON 백업·복원을 구현합니다. 승인·검수 상태는 `C:\test\docs\05_테스트결과.md`를 확인하세요. 외부 배포 완료와 로컬 개발 완료는 구분합니다.

Node.js 24로 `npm ci`, `npm run test`, `npm run build`, `npm run dev`를 실행합니다. 개발 주소는 http://127.0.0.1:5173 입니다. 같은 브라우저/주소의 IndexedDB에 기록을 저장합니다.

실제 운영 자료를 커밋하거나 공개하지 마세요. `public/sample.json`은 제공된 가상 샘플만 사용합니다. 백업 파일은 암호화되지 않으며 안전한 곳에 보관해야 합니다. 앱에 로그인·직원 권한·기기 간 자동 동기화는 없습니다.

Vercel에서 앱 폴더(`app`)를 프로젝트 루트, Vite를 프레임워크, `dist`를 출력 폴더로 설정합니다. `vercel.json`의 빌드 명령은 검사 실패 시 배포 빌드를 중단합니다. 운영 주소는 하나로 고정하세요. 현재 외부 저장소 생성·연결·운영 배포는 실행하지 않았습니다.
