# 프렙 카페 판매·재고·손익 MVP

단일 매장 운영자의 판매 입력 → 메뉴 수익성 → 기간 손익 → 재료 잔량·발주 참고 흐름을 연결하는 브라우저 프로그램입니다. 제공 자료는 가상 샘플이며, 실제 고객 정보나 운영 자료를 서버에 올리지 않습니다.

## 실행

Node.js 24를 사용합니다. `app` 폴더에서 `npm ci`, `npm run check`, `npm run dev`를 실행하세요. 주소는 `http://127.0.0.1:5173`입니다.

## 범위와 문서

- 기준 PRD: `doc/01_prd.md`
- 기능·기술 요구사항: `docs/02_FRD.md`, `docs/03_TRD.md`
- 개발계획·검수 기록: `docs/04_개발계획.md`, `docs/05_테스트결과.md`
- 프로그램: `app/`, 디자인 참고: `design/`

저장 자료는 같은 기기·브라우저·주소의 IndexedDB에 보관됩니다. 로그인, 공동 편집, 자동 기기 동기화, 실제 주문 전송은 지원하지 않습니다. 전체 백업 파일은 암호화되지 않으므로 별도로 안전하게 보관하세요.

## Vercel 준비

프로젝트 루트를 `app`, 출력 폴더를 `dist`, Node를 24로 지정합니다. 앱 폴더의 `vercel.json`은 검사 후 빌드와 보안 헤더를 설정합니다. GitHub 업로드는 배포 완료를 의미하지 않으며 실제 운영 배포 상태는 검수 문서를 확인하세요.
